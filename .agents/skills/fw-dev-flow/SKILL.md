# FolioWiki development flow

Read AGENTS.md, PRODUCT.md, DESIGN.md and architecture. Restate observable behavior and provider/security impact. Keep changes minimal/provider-neutral. Add proportional tests/docs. Run format check, lint, typecheck, tests and build. Report validation and remaining risk.
